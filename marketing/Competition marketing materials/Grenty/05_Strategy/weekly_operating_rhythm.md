# Weekly Operating Rhythm — Miami Salesperson

## Monday: Plan the Week
| Time | Activity | Owner |
|---|---|---|
| 9:00 AM | Review Weekly Scorecard (Sheet 3) | Manager + Salesperson |
| 9:30 AM | Triage Task Tracker (Sheet 1): set top 5 priorities for the week | Salesperson |
| 10:00 AM | Pipeline Review (Sheet 2): update stages, flag stalled deals | Both |
| 10:30 AM | Align on the week's focus: "What are the 3 things that matter most this week?" | Manager |

## Tuesday–Thursday: Execute
| Activity | Cadence |
|---|---|
| Outbound prospecting block (calls + emails) | Daily, 9–11 AM |
| Follow-up block (existing conversations) | Daily, 2–3 PM |
| End-of-day update to Task Tracker | Daily, 5 PM |
| Quick async check-in with manager (Slack/WhatsApp) | Daily, 5:30 PM |

## Friday: Review & Report
| Time | Activity | Owner |
|---|---|---|
| 10:00 AM | Update Weekly Scorecard (actuals) | Salesperson |
| 10:30 AM | Write "Top 3 Wins / Top 3 Blockers" summary | Salesperson |
| 11:00 AM | Friday Review Call (15 min): celebrate wins, name blockers, preview next week | Both |
| 11:30 AM | Manager writes coaching memo (Antigravity assists) | Manager |

---

## Monthly: Strategy Review (Last Friday of Month)
- Review 30/60/90 plan progress.
- Assess KPIs against targets.
- Identify process improvements.
- Recalibrate territory strategy if needed.
- File a monthly review document in `05_Strategy/`.

---

## Daily Workflow for the Salesperson
```
Morning:
  1. Open Task Tracker → identify today's P1 tasks.
  2. Prospecting block (9-11 AM).
  3. Log all touches immediately.

Afternoon:
  1. Follow-up block (2-3 PM).
  2. Prep for next-day meetings.
  3. Update Task Tracker.
  4. Send daily async check-in to manager.
```

## Daily Workflow for the Manager (You)
```
Morning:
  1. Review salesperson's previous day check-in.
  2. Flag anything that needs course correction.

Evening:
  1. Share any conversation/recording with Antigravity for processing.
  2. Review Antigravity's daily summary.
  3. Note coaching points for next 1:1.
```
