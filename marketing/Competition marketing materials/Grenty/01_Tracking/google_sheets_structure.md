## Sheet 1: Task Tracker

| Column | Description | Example |
|---|---|---|
| **Task** | Clear description of the task | Call back John at Berkshire |
| **Owner** | Who is responsible | Salesperson / Manager |
| **Related Account** | Brokerage or contact name | Berkshire Hathaway Miami |
| **Priority** | P1 (Critical) / P2 (High) / P3 (Normal) / P4 (Low) | P1 |
| **Status** | Not Started / In Progress / Waiting / Done / Blocked | In Progress |
| **Due Date** | When it must be done | 2026-03-20 |
| **Next Action** | The very next physical step | Send follow-up email with brochure |
| **Notes** | Context, history, or relevant info | Met at MLS event last week |
| **Blocker** | What is preventing progress (if any) | Waiting for pricing approval |
| **Last Updated** | Date of last change | 2026-03-16 |
| **Source** | How we got the lead/task | Compass scrape / Referral / Event |
